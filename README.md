Project Inspiration & Attribution
This project is a non-commercial fan-made browser game. Its technical foundation is derived from the MIT-licensed open-source Spaceship Shooter Game by Alfred Ang. The horizontal arcade-shooter presentation, stage structure, enemy flow, and general gameplay direction are inspired by Space Monkey 3: Bananas Gone Bad, the fictional arcade game featured in Grand Theft Auto V / Grand Theft Auto Online by Rockstar Games. All custom characters, including Tangniu and Niu Lai, and all newly created artwork, gameplay changes, and code modifications are part of this fan project. No original Rockstar Games source code or game assets are included.
